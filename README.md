# PinnedSpot public pages

The public web pages for PinnedSpot, an iPhone app: a short description and the privacy policy.
Served by GitHub Pages from the `main` branch. Plain static HTML, with no scripts, external fonts,
cookies or trackers.

The privacy policy is a draft until contact details and an effective date are added. Its source
text is maintained and reviewed with the application's source; changes are made there first and
copied here.
